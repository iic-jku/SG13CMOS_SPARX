# VACASK build for the Code-a-Chip notebook

`vacask-1b48553-ubuntu24.04-x86_64.tar.gz` is a build of [VACASK](https://codeberg.org/arpadbuermen/VACASK) at commit [`1b48553`](https://codeberg.org/arpadbuermen/VACASK/src/commit/1b48553c5b204bc11fb6f6d900b18f079fafc90e) (2026-09-29, version `0.3.4-88-g1b48553`). The notebook `SPARX_JKU_ISSCC2027.ipynb` unpacks it to `/foss/tools/vacask`.

The detector testbenches need `pac` and `pnoise`, which reached VACASK `main` on 2026-09-25 and 2026-09-28. No tagged VACASK release and no IIC-OSIC-TOOLS image carries them yet: the 2026.09 image ships `89e888d`, which has `hbnoise` but neither `pac` nor `pnoise`. `1b48553` is the commit the results in `testbenches/xschem/` were produced with.

| Built in | `us-docker.pkg.dev/colab-images/public/runtime` (Ubuntu 24.04, x86_64), the Google Colab runtime image, so the binary links against the libraries Colab has |
| Recipe | the IIC-OSIC-TOOLS install script (`_build/images/vacask/scripts/install.sh`): Boost 1.88.0 static (filesystem, process, asio) with `BOOST_PROCESS_V2_DISABLE_PIDFD_OPEN`, OpenVAF-Reloaded v24.0.2mob, `-march=x86-64-v2`, `OPENVAF_OPTIONS="--target_cpu generic"`, Release |
| Runtime | `apt-get install libklu2` on Ubuntu 24.04, the other libraries are part of the Colab image |
| Contents | the install tree without `openvaf-r` and without the Verilog-A sources (`src/`), and with the device models the SPARX testbenches need: the built-in resistor, capacitor, inductor, diode, op-amp and ideal line, the SPICE models, and VBIC 1.3, which the IHP-Open-PDK models load. VBIC comes from the public Verilog-A model collection of Dietmar Warning, as in the VACASK repository. BSIM3v3 and BSIM4.8 (CC-BY-NC 4.0) and BSIM-BULK (BSIM Group license) are left out, and so is PSP 103.4, since the PDK compiles its own PSP model. The IHP-Open-PDK models are generated by `sg13g2tovc` from the PDK in the notebook. |

The notebook builds the same commit from source with `BUILD_VACASK = 1`, which takes about 5 minutes on 8 cores and about 12 minutes on the two vCPUs of the free Colab tier.
